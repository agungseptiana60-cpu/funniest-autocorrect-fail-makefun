A text to a boss that was supposed to say a therapy appointment ran over, but the phone split "therapist" in two — so the sender is now, apparently, still sitting in a waiting room with the rapist. The program in `main.ts` writes that single line (103 characters) to `entry.txt` in the output directory.

## Run it

```sh
node main.ts
```

This writes `/output/entry.txt`. Outside the grader, set `MAKEFUN_OUTPUT_DIR` to choose the output directory.
